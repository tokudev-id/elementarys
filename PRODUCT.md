# Konteks produk

Sumber: PRD v1.3 dan Implementation Plan v2.0 yang disetujui Toku. Tidak ada asumsi kebutuhan baru.

Guru sekolah mencatat satu kelas melalui HP: menandai ketidakhadiran, mengonfirmasi sisanya hadir, lalu memeriksa hasil server. Admin mengelola identitas, kalender, kelas, siswa, guru dan rekap. Bahasa Indonesia, semua status berupa teks, target sentuh 44px, lebar 360/768/1024 dan rotasi mempertahankan pilihan. Nama sekolah berasal dari konfigurasi; data uji diberi label sintetis. Tidak membuat logo, foto, ilustrasi, testimoni atau klaim format SIKL.

Keberhasilan produk dinilai melalui akurasi rekap dan pengurangan pekerjaan guru. Bukti automation terpisah dari bukti perangkat nyata. Persetujuan scope ini sudah tercantum pada dokumen sumber, sehingga tidak diulang sebagai wawancara desain.
